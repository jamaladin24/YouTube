# فقط صدا (YtAudio)

اپ اندروید که لینک یوتیوب را می‌گیرد و فقط صدایش را پخش می‌کند.
در برنامه یوتیوب: «اشتراک‌گذاری» ← «فقط صدا».

## ساخت فایل APK با GitHub (بدون نصب هیچ برنامه‌ای)

1. در github.com یک مخزن (repository) جدید بسازید.
2. «Add file ← Upload files» را بزنید و **محتوای** این پوشه را آپلود کنید
   (پوشه `.github` هم باید آپلود شود؛ اگر پنهان بود، آن را جدا بسازید:
   `.github/workflows/build.yml`).
3. به تب **Actions** بروید؛ ساخت خودکار شروع می‌شود (حدود ۳ تا ۵ دقیقه).
4. روی اجرای سبز‌شده کلیک کنید و از بخش **Artifacts** فایل `YtAudio-apk` را دانلود کنید.
5. فایل zip را باز کنید، `app-debug.apk` را روی گوشی بریزید و نصب کنید
   (اجازه «نصب از منابع ناشناس» را بدهید).

## ساخت با Android Studio

پوشه را در Android Studio باز کنید (Open) و
`Build ← Build App Bundle(s) / APK(s) ← Build APK(s)` را بزنید.

## پخش در قفل صفحه

بار اول اپ می‌پرسد که از «بهینه‌سازی باتری» خارج شود؛ «اجازه» بدهید.
در گوشی‌های شیائومی، هواوی و سامسونگ در تنظیمات برنامه، «Autostart» یا «بدون محدودیت باتری» را هم روشن کنید.
از اعلان می‌توانید پخش را متوقف یا اپ را ببندید.

## فایل‌ها

- `app/src/main/assets/index.html` — رابط کاربری و پخش‌کننده
- `MainActivity.java` — دریافت لینک از منوی اشتراک‌گذاری و نمایش صفحه
- `PlaybackService.java` — اعلان «در حال پخش» تا پخش در پس‌زمینه قطع نشود
- `KeepAliveWebView.java` — پنهان نشدن صفحه وب هنگام قفل صفحه
